## 首个接入模型 — 2026-10-01

## 场景与建议

| 场景 | 优先评估路线 | 必须验证的结果 |
|---|---|---|
| 普通横排中文当前页、题名/版权页 | 首个在线适配器选 PP-OCRv6；通用高精度或腾讯可作后续独立对照 | 字符、页码、关键书目字段和延迟；机器结果仍待复核 |
| 横排英文正文 | VL保留为后续接入选项；本样本优于PP，尚未启用 | 漏行、变音符、阅读顺序、真实成本与延迟 |
| 繁体竖排、夹注、多栏扫描 | PP-OCRv6 与带版面分析的文档解析 API 对照，再与专业本地模型比较 | 列序、整列遗漏、夹注归属、异体字；不能只看字符置信度 |
| 普通整书扫描 | 先比较现成文档解析模型与本地通用引擎，逐页保存进度 | 完整覆盖、可恢复、页费/传输、错误页重试和阅读顺序 |
| 蒙古文拉丁转写、特殊历史字形 | 按实际字符集选专用模型，必要时用同类材料微调 | 未参加训练的新书盲测、变音符和码位保真 |
| 传统竖写蒙古文 | 独立文字系统资格验证 | 当前尚无可交付准确率；不可由拉丁转写模型推断 |
| 不外发的研究材料或免费额度耗尽 | 成员显式选择并下载到自己的设备处理 | 不自动转向 Owner 电脑或收费服务 |

在线/离线描述计算位置；通用预训练/专门微调描述模型能力。云端 OCR 同样使用训练模型，自训也不天然更准。当前建议是按实际页面质量选择，而不是把整书一律分给自训引擎。

## 训练模型与准确率结论

现有 Mongology 模型主要是横排拉丁转写/西文学术行模型，且部分规范化会合并不同学术字符；既有验证 CER 不能移用为新书、繁体古籍或传统蒙古文的准确率。西文学术模型的最优 checkpoint 与最后 epoch 的变音符成绩也不能混用。曾使用 PDF 文字层提供行框的整书导出，不证明纯扫描文档的切列、切行与阅读顺序可靠。详见[本地资格报告](current-page-and-book-ocr.md)。

已冻结 4 份来源、8 个完整页面、6,719 个参考字符，并完成本轮两引擎的同页试测，实测 CER 及失败/恢复口径见上文。参考由独立 agent 看图转录，未经人工核验，并记录 2 处疑字。样本仅覆盖横排汉英与书目页，不能认证竖排古籍或整书。专业模型需先通过未训练书页的分层盲测，分别报告字符、异体/变音符、漏列、顺序和人工校对成本。

## “连接 OCR 引擎”弹窗的教程要求

Owner 明确要求教程就在按钮打开的界面内，简单易懂。这是接入功能的验收项，不能只放外部开发文档。以下是产品文案/流程要求，不代表目前已存在可用的下载器或连接按钮。

默认展示“在线服务”和“本地引擎”两项，不展示协议、端点、令牌刷新等实现术语。每项给三步引导和一个真实的“测试连接”操作；连接测试不发送正在阅读的书页。优先查询身份和识别能力；服务商没有相应检测接口时，使用内置测试图并事先说明可能产生的小额费用。只取得登录令牌不能显示“识别可用”。书页识别另由“识别当前页”明确发起。

**在线服务**

1. **选择服务。** 选择你要使用的 OCR 服务，点击旁边的“开通教程”。教程标明账号开通、实际计费及停用方法，官方链接在旁边可查。
2. **填写连接信息。** 按服务名称显示所需字段，例如“API Key（应用密钥）”与“Secret Key（保密密钥）”，附“在哪里找到”的短说明。不收集服务商登录密码。
3. **测试连接。** 成功显示“已连接，可以识别当前页”；失败直接说明“密钥不正确”“未开通识别服务”或“额度不足”，给出对应修复入口。

必要提示：“识别费用由你的 OCR 服务账号承担。在线识别会将所选页面发送给该服务。”不在教程中承诺统一准确率、永久免费或所有服务不留存。

**本地引擎**

1. **安装连接程序。** 从正式发布的下载入口安装到你自己的电脑；支持系统和下载大小清楚标明。未发布安装包时不能提供虚假下载按钮。
2. **选择识别引擎。** 下载已支持的模型，或在连接程序里选择已安装引擎；用“适合普通书页”“适合你的专用文字模型”等用途说明，显示所需空间。
3. **连接这台电脑。** 完成账号配对并测试。离线时显示“这台电脑未连接，请先打开连接程序”，不退回 Owner 电脑。

已有合适引擎时提示“这台电脑已有可用引擎，可以直接连接”；不要要求重复下载。不适合当前文字或缺少位置能力时说明具体限制，并让用户自行选择其他已支持引擎或在线服务。

必要提示：“识别在你自己的电脑运行，使用本机算力；所选本地适配器不调用云 OCR。识别结果是否保存到平台，按实际保存选项说明。”不能把“本机识别”误写成“平台从未接触该书”或“结果永不联网”。

弹窗支持键盘关闭/焦点返回、窄屏滚动、中文/英文、切换方式保留当前草稿；未保存凭据不进入 URL、日志或普通浏览器存储。教程与支持的适配器版本一起更新。高级自定义连接说明折叠显示，普通用户无需先读 API 文档。
