# L1-UX01 — Bilingual UI + Upload UX + Correct Browser Preview

## Task ID
L1-UX01 — Bilingual UI + Upload UX + Correct Browser Preview

## Goal
Resolve the first real-browser usability defects: complete zh-CN/en UI switching, explicit upload phases/speed/ETA with bounded concurrency/stall handling, and browser-correct Preview plus Unicode-safe downloads.

## Scope
- typed zh-CN/en localization and persistent language selection;
- upload phases, real network progress/speed/ETA, inactivity timeout, concurrency-2 queue;
- dedicated OSS browser endpoint for inline Preview while native service endpoint remains authoritative for storage control-plane operations;
- Unicode-safe attachment Content-Disposition;
- reviewed production-gate preparation for `files.ajtlab.top` and CSP integration.

## Non-goals
No multipart/resumable upload, Transfer Acceleration, CDN, backend byte proxy, public bucket, Layer 2/3 expansion, or unrelated redesign.

## Acceptance Criteria
Localization, upload scheduler/liveness/metrics, preview/download authorization and Unicode filename behavior are deterministic and tested; CSP/security are not weakened; canonical checks pass; production activation occurs only through separate reviewed gates.
