## Task ID
L1-UX04 — First-Use Core Drive UX Polish

## Goal
Apply two small first-use Drive UX fixes without changing storage semantics: clear same-folder duplicate-name feedback and persistent desktop sidebar navigation.

## Scope
Preserve the existing same-folder uniqueness constraints and improve the upload conflict message so the user is told the file was not duplicated. Keep same names in different folders valid. Make the desktop sidebar remain visible while scrolling long file lists, correctly below the existing sticky top bar, without changing navigation state or mobile behavior.

## Non-goals
- No checksum/content-level deduplication, automatic renaming such as `(1)`/`(2)`, new navigation destinations, Drive model changes, or mobile redesign.

## Acceptance Criteria
- Active/pending same-name conflicts in the same folder remain rejected by the existing authoritative constraint.
- The frontend shows a clear localized duplicate-name message instead of a generic failure.
- Same names in different folders continue to work.
- Desktop Library/Favorites/Pending/Recycle navigation remains visible during long vertical scrolling and does not overlap the sticky top bar.
- No unnecessary second page scrollbar is introduced; current responsive/mobile behavior remains intact.
- Focused frontend/API regression tests plus one typecheck/build pass are sufficient when green.
