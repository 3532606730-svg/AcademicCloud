# L1-UX02 — Academic Workspace Visual Refresh & Drag-and-Drop Upload

## Task ID
L1-UX02 — Academic Workspace Visual Refresh & Drag-and-Drop Upload

## Goal
Transform the existing functional engineering UI into a refined contemporary
digital research-library workspace, while adding safe drag-and-drop multi-file
upload using the existing upload pipeline. FRONTEND-ONLY unless a test proves
an unavoidable frontend contract issue.

## Scope
- Visual token system + typography contract (local/system fonts only; no UI
  framework, icon package, or remote fonts).
- Workspace header redesign (root vs nested hierarchy, no eyebrow, no
  redundant root breadcrumb, compact) + command bar (新建文件夹 / 上传文件).
- New Folder as a compact accessible dialog (focus on open, Enter submits,
  Escape closes, success closes, max length enforced, focus returns).
- Sidebar/topbar refresh: keep ONLY functional views (Library / Pending /
  Recycle Bin); deep forest sidebar with dependency-free inline SVG icons;
  topbar = brand + language switch + account identity + logout.
- File/folder list as an archive catalogue (名称/大小/修改时间/actions,
  56–60 px rows, quiet metadata, no raw MIME strings, real folder/type icons).
- Row action menu: one compact `⋯` trigger per row; folder (Rename / Move /
  Move to Trash), file (Preview when previewable / Download / Rename / Move /
  Move to Trash); accessible, keyboard reachable, Escape + click-outside close,
  existing confirmation semantics for destructive actions.
- Drag-and-drop upload in the LIBRARY view only: temporary full-workspace
  drop overlay on real file drags (forest tint, restrained border, 120–180 ms,
  drag-depth counter); drop snapshots the current folder id exactly once and
  enqueues regular files with that pinned destination (MAX_CONCURRENT_UPLOADS
  = 2 preserved; existing pipeline only). Directory drop: skip + localized
  message; mixed drops upload regular files and report skipped directories.
- Upload queue visual refresh (no semantic change).
- i18n: every new visible string in zh-CN and en.
- Accessibility + responsive behavior preserved/improved.

## Non-goals
- No production deployment / Alibaba / OSS / DNS / TLS / Nginx / systemd /
  production DB mutation; no permanent delete.
- No Layer 2; no Favorites (L1-FAV01, future); no recursive folder recycle
  (future); no directory traversal upload; no `webkitdirectory`.
- No API/schema/storage lifecycle changes; no new dependencies.
- No search/sort/view controls, no fake navigation.
