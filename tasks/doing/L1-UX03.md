# L1-UX03 — Dedicated Mobile Experience & Zero-Descriptive-Copy UI

## Goal
Make mobile a first-class presentation of the SAME React app/API/state (no
second frontend, no UA detection): bottom navigation, dedicated mobile
catalogue rows, fullscreen preview, mobile-friendly dialogs and upload queue —
plus a hard zero-descriptive-copy cleanup across every viewport. Desktop layout
and all backend semantics stay stable.

## Scope
- Copy policy: every visible string must identify/label/expose/report/confirm.
  Delete login marketing (eyebrow/slogan/subtitle/privacy/Welcome back),
  section-copy paragraphs (pending/recycle), empty-state second sentences,
  preview eyebrow/expires/"open in new tab", move/new-folder eyebrows and
  placeholders, outside-workspace drop sentence (now silent), "Verify or retry"
  → "Retry". Dead keys removed from both catalogs.
- Mobile presentation (pure CSS/media queries, one primary <= 768px breakpoint):
  - desktop sidebar becomes a fixed safe-area bottom navigation (same four
    real destinations, icon + short label, >=44px targets, aria-current kept);
  - compact mobile topbar (brand + avatar account menu with language/sign-out);
  - dedicated mobile catalogue rows (icon, single-line truncated filename,
    type · size / 文件夹 metadata line, star + more always visible);
  - compact `[←]` back control instead of six-level breadcrumbs; path model
    unchanged (h1 stays the current folder name);
  - fullscreen 100dvh Preview with compact toolbar (close / filename / Open);
  - New Folder and Move dialogs usable with touch + mobile keyboard, safe-area
    aware, >=44px actions;
  - upload queue stacks vertically with concise state/metrics;
  - no page-level horizontal scroll at 360/390/430.
- RowMenu fix: scroll/resize closure no longer drops keyboard focus on a
  detached menu item (restores trigger focus when focus was inside).
- Tests: copy-audit regression, mobile nav/catalogue/preview structure,
  RowMenu focus guarantees, silent outside-workspace drop, account menu,
  stylesheet structure assertions.

## Non-goals
- No second frontend/native app/PWA, no UA detection, no new dependency.
- No Search/Settings/registration/AUTH02/Shared Library/OCR/RAG/tags/notes.
- No desktop redesign beyond the required copy cleanup; preview/favorites/
  upload/drop/permanent-delete semantics unchanged; CSP untouched (no inline
  styles); production untouched; no merge to main, no deploy.
