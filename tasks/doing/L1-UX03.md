# L1-UX03 — Dedicated Mobile Experience & Zero-Descriptive-Copy UI

## Task ID
L1-UX03 — Dedicated Mobile Experience & Zero-Descriptive-Copy UI

## Goal
Make mobile a first-class presentation of the same React app/API/state while removing nonessential descriptive UI copy. Desktop behavior, Favorites, upload/drop semantics, preview security, and CSP must remain stable.

## Scope
- zero-descriptive-copy cleanup across login/library/favorites/pending/recycle/preview/dialogs/upload/drop;
- one responsive app, no UA detection or second frontend;
- compact mobile topbar/account menu;
- fixed safe-area bottom navigation using the four real destinations;
- dedicated mobile catalogue rows;
- compact back control for nested folders;
- fullscreen 100dvh Preview;
- mobile New Folder/Move/upload-queue presentation;
- RowMenu scroll/resize focus repair;
- regression tests and local layout audit.

Independent-review repair scope now additionally requires:
- exact bottom-nav DOM/semantic/visual order `Library / Favorites / Pending / Recycle`;
- Preview action set `Close / Open / Download`, with Download reusing the normal authoritative download flow;
- approximately 44px mobile targets for Sign In, AccountMenu Sign Out, 中文, and EN.

## Non-goals
No second/native/PWA frontend, UA detection, registration, Accounts I, Shared Library, OCR/RAG, tags/search, production deployment, main merge, CSP weakening, or new dependency.

## Acceptance Criteria
- zero-descriptive-copy policy is real and not implemented by CSS hiding;
- exact mobile nav semantic order is Library/Favorites/Pending/Recycle;
- Preview exposes Close/Open/Download and preserves inline-preview vs normal-download authorization paths;
- mobile touch targets meet the intended approximately 44px floor for the remaining controls;
- RowMenu focus behavior is correct on scroll/resize;
- no mobile horizontal page scroll at 360/390/430;
- desktop sidebar/catalogue/Preview remain coherent;
- Favorites/drop-guard/CSP/security semantics remain unchanged;
- canonical tests/typecheck/build/acceptance/diff checks PASS;
- dependency delta remains zero;
- independent review PASS before closure.
